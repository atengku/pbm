# PBM & CBDC Research Library

A curated library of **Monetary Authority of Singapore** primary source papers on
programmable / purpose-bound money and central bank digital currency.

- **Original White Paper** — PBM Technical Whitepaper (2023)
- **Retail Digital SGD** — Project Orchid (Phase 1, Blueprint, retail-CBDC economics)
- **Wholesale CBDC** — the full Project Ubin series (2016–2020) + Cedar × Ubin
- **Adjacent** — Project Guardian tokenisation papers

`index.html` is a static landing page linking each paper (served from `/papers`).
All documents © MAS, hosted for reference and study. Source: mas.gov.sg.

Deploys to Vercel automatically on push to `main`.
